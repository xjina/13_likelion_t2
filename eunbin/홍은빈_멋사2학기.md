**<영상 1>**

대규모 언어 모델 : 어떤 텍스트를 입력했을 때 다음에 올 단어를 예측하는 정교한 수학적 함수. 확률을 구하는 함수

단어에 대한 예측 -> 파라미터(가중치)를 통해 이루어짐

가중치 조정 -> 역전파



1\. pretraining : 텍스트를 통해 다음 단어를 예측

2\. RLHF : 강화 학습 - 사람이 모델에 잘 못 된 응답을 수정 또는 더 나은 답변을 고름



2017년 이전 ; 대부분의 모델은 단어를 하나씩 순차적으로 병렬 처리

구글 transformers ; 전체 문장을 한 번에 병렬 처리 -> 각 단어는 벡터 값(해당 단어의 의미를 담음)으로 변환하여 사용

 	-Attention : 연산 알고리즘, 숫자 벡터 처리 -> 숫자 벡터들이 정보를 주고 받아서 주변 맥락을 파악하게 함.

 	-Feedforward : 많은 언어 패턴을 저장할 수 있도록 함.

 	\*Attention과 Feedfoward의 반복 ->  각 단어 벡터가 맥락을 잘 반영하도록 함. -> 다음의 올 단어의 확률 분포 예측





**<영상 2>**

1\. 인공지능, 딥러닝, 머신러닝의 공통점 : 패턴과 특징을 찾음.

2\. 러닝의 개념과 차이점

\- 인공지능(가장 상위 개념) :  알고리즘을 이용해서 시스템 자체(고차원적인 것)를 다루는 것

\- 머신러닝 : 문제를 풀기 위한 알고리즘, 그 특징으로부터 알 수 있는 것

\- 딥러닝(가장 하위 개념) : 특징을 찾아내는 뉴럴 네트워크의 구조가 복잡하고 깊게 설계

3\. 학습 방법

-Supervised Learning(지도 학습) : 문제(분류/회기-값으로 답이 나옴)와 그 정답을 알려줌 -> 왜 답이 이렇게 나오는지 특징을 찾음. encoder-특징 찾아냄, decoder-정답 도출

-Unsupervised Learning(비지도 학습) : 특징을 통한 그룹화. 주요 값과 불필요한 값을 분류

-Semi-Supervised Learning(세미-지도 학습) : 답이 주어진 문제와 그렇지 않은 문제 -> 답이 주어진 문제를 통해 답이 주어지지 않은 문제를 해결

\- Rainforcement Learning(강화 학습) : 인공지능이 도출한 답에 점수를 줌. 최고 점수 받는 것을 목표로 함.
